Os dois juízes

Cada afirmação da matéria é um alfinete. Para a direita, a frase achada é mais parecida com a afirmação; para cima, o verificador vê mais sustentação. Arraste os dois barbantes de corte e veja quais afirmações mudam de resultado.

Nenhum destes resultados foi conferido por uma pessoa. Os cortes que você escolher aqui mudam só esta página: servem para ver quão perto de cada linha cada afirmação está.
